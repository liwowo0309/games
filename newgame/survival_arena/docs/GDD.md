# 疾锋战区 — 游戏设计文档 (GDD)

| 版本 | v0.1 |
|------|------|
| 日期 | 2026-08-06 |
| 平台 | 微信小游戏（Cocos Creator 3.8） |
| 原型 | `prototype/` 浏览器可玩 |

---

## 1. 一句话

8～10 分钟一局的 16 人第三人称快局大逃杀 — 跳伞、搜刮、缩圈、决赛，成人「再来一局」。

---

## 2. 核心循环

```
匹配 → 跳伞选点 → 搜刮装备 → 遭遇战 → 缩圈推进 → 决赛圈 → 结算奖励 → 再来一局
```

| 层 | 时长 | 内容 |
|----|------|------|
| 秒级 | 持续 | 移动、瞄准、射击、换弹 |
| 分钟级 | 8～10 分 | 单局完整体验 |
| 小时级 | 30～60 分 | 每日任务、通行证进度 |
| 天/赛季 | 每日 | 登录补给、赛季段位 |

---

## 3. 对局规格

| 参数 | 数值 |
|------|------|
| 单局人数 | **16**（真人 + bot 混排） |
| 真人上限 | 12（不足 bot 补位） |

| ID | 名称 | 类型 | 伤害 | 弹匣 | 射速 | 特点 |

## 5. Bot AI（原型）

| 行为 | 说明 |
|------|------|
| 漫游 | 随机巡逻 + 朝安全区中心偏移 |
| 交战 | 视野内敌人 → 追击射击 |
| 缩圈 | 圈外加速跑向圈内 |
| 难度 | 命中率 25%～40%，反应 0.3～0.8s |

Bot 名称随机中文/英文混合，避免「一眼假」。

## 7. 上瘾设计

- **多维结算**：排名分 + 击杀分 + 生存分，减少「必须吃鸡」挫败
- **每日首胜**：额外币 + 通行证经验
- **连续登录**：7 日链奖励
- **一键再来**：结算页 3 秒内可点
- **外观社交**：击杀播报、入场动作（IAP）

---

## 8. 世界观（原创）

**疾锋战区** — 近未来私人军事承包商在封闭岛上进行的「生存竞技合约」。地图名：**灰岩岛 (Grayrock)**。无现实军事单位名称，无和平精英素材。
