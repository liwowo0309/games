## 1. 主体与账号

| 项目 | 说明 |
|------|------|
| 微信小游戏 | 需 **企业主体** 注册小游戏账号 |
| 软著 | 申请软件著作权（约 ¥300～800 代办） |
| 版号 | 长期全量 IAP 需规划；前期可用测试/体验类目积累数据 |
| 收款 | 微信支付商户号绑定企业主体 |
| 税务 | 企业记账报税 |

**开发者若未满 18 岁**：由家长（18+）担任账号持有人与收款主体。

---

## 2. 隐私与适龄

- [ ] 隐私政策页面（收集：设备 ID、对局数据、支付记录）
- [ ] 用户协议
- [ ] 适龄提示：**12+** 或按微信要求
- [ ] 首次启动隐私弹窗同意
- [ ] 家长监护说明（若有未成年用户）

隐私政策草稿要点：

- 不收集通讯录、精确地理位置（仅用于匹配区域可选）
- 对局数据用于反作弊与平衡
- 不向第三方出售个人数据
- 联系邮箱用于删除账号请求

---

## 3. 内购合规

- [ ] 所有价格界面明示人民币金额
- [ ] 首充礼包标注「仅可购买一次」
- [ ] 无真钱抽奖箱、无赌博机制
- [ ] 沙盒测试通过后再开正式支付
- [ ] 退款政策说明（按平台规则）

---

## 4. 广告合规

- [ ] 仅激励视频，对局内无强制插屏
- [ ] 广告 SDK 按微信小游戏规范接入
- [ ] 未成年人广告展示遵守平台限制

---

## 5. 内容合规

- [ ] 无血腥写实表现（击中反馈用光效/数字）
- [ ] 无现实国家/军队商标侵权
- [ ] 无政治敏感内容
- [ ] 原创 UI、地图、角色命名

## 7. 版号策略（长期）

1. **第 1～4 月**：软著 + 小游戏测试，积累留存数据
2. **门禁通过后**：评估版号申请成本与时间
3. **备选**：先海外 Google Play 测试（需另开合规）
