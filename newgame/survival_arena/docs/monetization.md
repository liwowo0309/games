## 1. 月收入公式

```
月毛收入 = IAP收入 + 广告收入

IAP收入 = 月付费用户数 × 付费用户月均消费
广告收入 = 月激励视频展示次数 × eCPM / 1000

月净收入 ≈ 月毛收入 × (1 - 平台分成率) - 服务器月费
```

**平台分成**：微信小游戏 IAP 约 40% 给平台；广告约 30%～50% 给平台。粗算 **净收入 = 毛收入 × 0.55～0.65**。

### 向 ¥10,000 净收入靠拢的测算

| 路径 | 假设 | 月毛收入 | 月净收入（×0.6） |
|------|------|---------|----------------|
| A 仅 IAP | DAU 1500，付费率 4%，付费用户月消费 ¥55 | ¥13,200 | ≈ ¥7,920 |
| B IAP+广告（推荐） | IAP 毛 ¥7,000 + 广告毛 ¥9,000 | ¥16,000 | ≈ ¥9,600 |
| C 高 DAU 广告 | DAU 2000，人均 10 次/日，eCPM ¥25，30 天 | 广告毛 ¥15,000 | 需配合 IAP |

**路径 B 广告部分拆解**：

```
DAU 1500 × 人均 8 次/日 × 30 天 = 360,000 展示/月
360,000 / 1000 × ¥25 eCPM = ¥9,000 毛
```

## 5. 第 4 月收入门禁 KPI

软启样本：**200～500 真实用户**，连续观察 **14 天**。

### 5.1 继续条件（满足 **≥ 4 项**）

| KPI ID | 指标 | 门槛 |
|--------|------|------|
| `d1_retention` | D1 留存 | ≥ **28%** |
| `d7_retention` | D7 留存 | ≥ **8%** |
| `session_length` | 平均单次游戏时长（分钟） | ≥ **18** |
| `matches_per_day` | 人均日开局数 | ≥ **2.5** |
| `ad_views_per_day` | 激励视频人均日观看 | ≥ **3** |
| `iap_conversion` | 沙盒 IAP 转化率 | ≥ **2%** |
| `shop_click_rate` | 商店点击率（备选） | ≥ **8%** |
| `ad_ecpm` | 7 日广告 eCPM（毛） | ≥ **¥15** |

### 5.2 立即停止或 pivot（任一触发）

| 条件 | 说明 |
|------|------|
| `KILL_D7_LOW` | D7 < **5%** 且人均日开局 < **1.5** |
| `KILL_NO_MONETIZE` | 沙盒 **0 付费** 且广告人均 < **1 次/日** |
| `KILL_FUN` | 开发者自测 10 局不愿继续 |

### 5.3 Pivot 方向

微信 **轻竞技**（2v2/4v4 房间射击）— 赚钱概率约 **25%～35%**。
