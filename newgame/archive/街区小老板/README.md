# 街区小老板

面向 10～15 岁的放置经营 Web 原型。**无广告**，本地存档。

## 怎么玩

打开 [`index.html`](./index.html)。

### 有策略的部分（别只会挂机）

1. **接待客人**：街上冒泡的客人要点，限时内点到才赚钱；连续点可**连击加成**，漏单打断连击  
2. **定价**：亲民价 / 公道价 / 精品价 —— 客流与客单价对调，精品价更吃操作  
3. **方针**（互斥，切换有冷却）：高峰盯梢 / 挂机托底 / 省钱装修  
4. **专精**（二选一永久）：夜市（离线强）或午高峰（接待强）  
5. **促销**：花启动金换 45 秒接待翻倍，投不投看你会不会赚回来  

挂机升级仍然有，但**会玩的人靠接待+决策明显更快**。
