# 《都市大亨》

成人向都市成长经营。**俯视 3D 街道**，可操控小人。打开 [`index.html`](./index.html)（需联网加载 Three.js）。

## 怎么玩

1. **移动**：右下角摇杆或 WASD / 方向键  
2. **进店**：走到店门口按 **E**，或直接点店铺 / 头顶标签  
3. **我的店**（金色光环）：经营主玩法——  
   - **金币**：扩建店面、做大招牌、业态升级、员工加薪  
   - **钻石**：雇佣员工（兼职 / 咖啡师 / 店长助理）  
   - **里程碑**：升级与成交达标后领取磨豆机、咖啡机等设备  
4. **别人的店**：进店点单吃喝（花都市币）  
5. **决策 / 账单**：定价、行情涨跌、大额水电地租冲击  
6. **商店 / 联机 / 商战**：底栏切换  

## 让人坐得住的五层循环

| 层 | 节奏 | 内容 |
| --- | --- | --- |
| 秒级 | 每 1～3 秒 | **客流高峰**里点客人，连击 10 触发 ×3 爆发 |
| 分钟级 | 约 2 分钟一波 | 高峰开始/结束、结算奖励；钻石可提前召唤 |
| 十几分钟 | 每 14 次操作左右 | **宝箱**：点客人 / 成交 / 升级都攒进度，攒满立刻开 |
| 小时级 | 一直有下一个 | **目标链** 33 个连续目标，完成即领、立刻推下一个 |
| 天/赛季级 | 每天 + 30 级 | 每日任务、**今日在线时长奖励**（5→120 分钟）、**赛季通行证** |

## 变现设计（清晰、不做真钱抽奖）

- **赛季通行证 ¥30**：30 级免费轨 + 高级轨，买了立刻补发已达成等级
- **成长基金 ¥18**：随通行证等级返钻，累计返还高于售价
- **月卡 ¥12 / 季卡 ¥30**：离线 8 小时、每日钻石、+5% 产速
- **钻石包**：首充双倍（只一次，界面明示）
- **钻石消耗口**：雇员工、每日限定装扮（每天轮换 3 件）、召唤高峰、立刻开箱、跳过目标
- 不含广告、不含真钱抽奖箱；沙盒支付不会真实扣款
