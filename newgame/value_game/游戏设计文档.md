# 《都市大亨》游戏设计文档

| 字段 | 内容 |
|------|------|
| 工作标题 | 都市大亨 |
| 品类 | 放置 / 都市模拟经营 / 成长 |
| 平台 | Web 原型 → Android + iOS APP |
| 目标用户 | 大人向深度经营；内容干净，青少年也可玩 |
| 变现 | **无广告**；装扮 / 钻石 / 月卡 |
| 收入目标 | 稳定期平均月收入约 **人民币 1 万元** |
| 联机 | 一期轻联机；二期重联机 |
| 文档版本 | v1.0 |
| 日期 | 2026-08-04 |

**一句话**：在可成长的都市里开店扩产、装扮总部、比营收与参观；付费买好看与省时。

---

## 1. 产品定位

- **动机**：当老板、看数字涨、把城市装好看、短时决策刷一下
- **会话**：5～15 分钟日常 + 离线挂机
- **付费**：愿为皮肤、主题、月卡便利付小额；反感逼氪、抽卡
- **边界**：无广告、无开放聊天、主线不锁进度、不做 pay-to-win 碾压

## 2. 核心循环

**在线**：经营决策 → 升级产速 → 解锁业态/城区 → 装扮展示 → 再经营  

**离线**：挂机产币（封顶）→ 营业报告领取 → 投入升级/装扮 → 再离线  

**策略层**：定价三档、经营方针、市场行情、供应链等级、订单接待连击  

## 3. 业态（MVP 6 店 + 2 城区）

| 顺序 | 业态 | 城区 | 解锁示意 |
|------|------|------|----------|
| 1 | 路边摊 | 旧城区 | 开局 |
| 2 | 咖啡店 | 旧城区 | 路边摊 Lv.5 |
| 3 | 便利店 | 旧城区 | 咖啡店 Lv.6 |
| 4 | 电竞馆 | 新城 | 便利店 Lv.8 + 评级 B |
| 5 | 物流站 | 新城 | 电竞馆 Lv.6 |
| 6 | 综合商场 | 新城 | 前五店达标 |

货币：**都市币（软币）** 主进度；**钻石** 装扮与便利。钻石不买关键店解锁。

## 4. 变现

| 商品 | 价格 | 说明 |
|------|------|------|
| 月卡 | ¥12/月 | 离线 4h→8h、每日钻石、+5% 产速、边框 |
| 季卡 | ¥30/季 | 月卡权益 + 限定称号 |
| 装扮/主题 | ¥3～12 | 形象、总部、灯光 |
| 钻石/加速包 | ¥6～30 | 日上限；无抽卡 |

月入约 1 万路径（设计假设）：约 **DAU 500 × 付费率 4%～5% × ARPU ¥18**。

## 5. 联机分期

### 一期（轻）
游客 ID、云存档、周榜（营收/装扮）、参观点赞、内购收据校验占位  

### 二期（重）
限时商战、公会/商盟、异步竞品挑战、定时皮肤拍卖（非赌博）  

不做：开放世界实时同屏、自由文字/语音聊天  

## 6. 合规与家长上架

- 开发者账号、收款、税务需 **家长（18+）** 办理  
- 适龄提示、隐私政策、购买需确认  
- 中国区按政策预留实名/防沉迷开关  

## 7. 里程碑

M0 文档 → M1 核心原型 → M2 内容+商店 → M3 轻联机 → M4 沙盒 IAP → M5 上架冲 DAU → M6 重联机  

## 8. 成功标准（上线约 3 个月）

新手 10 分钟完成率 ≥70%；D1≥35% / D7≥12%；付费率≥4%；ARPU≥¥15；DAU 向 500；月收入向 ¥10,000；广告始终为 0。
