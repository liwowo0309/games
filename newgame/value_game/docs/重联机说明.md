# 重联机说明（M6）

本原型在「商战」页已实现可玩的本地模拟版本，正式上线需换成真实后端。

## 已实现（客户端模拟服）

| 功能 | 说明 |
|------|------|
| 限时商战 | 1 小时内累计赚币，达标领钻石 + 勋章框 |
| 商盟 | 三选一加入；统计盟内周贡献（无私聊） |
| 异步竞品挑战 | 押注后按综合分结算胜负 |
| 定时拍卖 | 明码钻石一口价，非随机抽卡 |

数据存在本机 `localStorage` 的联机库中，与轻联机周榜共用模拟资料库。

## 正式后端建议

- 鉴权：游客 ID → 可选账号绑定  
- 商战：房间/赛季表 + 贡献流水  
- 公会：成员表 + 周贡献聚合  
- 挑战：挑战请求与结果落库，防重放  
- 拍卖：服务器时钟轮换商品与库存
