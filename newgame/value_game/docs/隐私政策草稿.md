本政策适用于《都市大亨》及相关服务。

## 我们收集什么

- **游客标识**：随机生成的玩家 ID，用于存档与排行榜  
- **游戏进度**：业态等级、货币、装扮、任务进度（本地及可选云存档）  
- **购买记录**：由应用商店处理支付；我们仅保存订单号用于发货与客服  
- **设备信息（正式版）**：设备型号、系统版本、崩溃日志（用于稳定性）  

我们**不**收集精确位置、通讯录、相册（非必要不申请）。  
我们**不**提供开放聊天，排行榜仅展示昵称与分数。

## 我们如何使用

- 提供与改进游戏体验、云存档、排行榜、内购发货  
- 履行法律义务与处理退款争议  

## 共享

- 支付由 Apple / Google / 国内应用商店处理  
- 若使用统计分析或云服务（如 Firebase），仅传输实现功能所需的最小数据  

## 儿童与家长

本游戏面向可独立游玩的用户，内购需家长同意。监护人可联系我们协助删除账号数据。

## 您的权利

可请求查阅、更正、删除与账号相关的个人数据（游客存档可在设置中重置）。
