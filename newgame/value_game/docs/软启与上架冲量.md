# 软启与上架冲量

## M4 软启（沙盒 / 小范围）

目标：验证循环是否好玩、付费点是否清楚，**不是**立刻月入一万。

| 检查项 | 目标 |
|--------|------|
| 新手 10 分钟完成率 | ≥ 70% |
| 玩家是否理解定价/行情/供应链 | 访谈 5～10 人 |
| 沙盒「购买」转化意向 | 愿意为装扮/月卡付费的比例 |
| D1（若有安装包） | ≥ 35% |

操作：

1. 打开 `index.html` 或打成 WebView/测试包发给亲友  
2. 商店内购保持沙盒；看 [`家长上架清单.md`](./家长上架清单.md) 准备账号  
3. 记录：卡关点、弃坑分钟数、最想买的商品  

## M5 上架冲 DAU

月入约 ¥10,000 的设计门槛（假设）：

- DAU ≈ **500**  
- 付费率约 **4%～5%**  
- 付费用户月 ARPU ≈ **¥18**  

动作建议：

1. 双端商店上架 + 适龄提示 + 隐私政策链接  
2. 素材：离线领取数字、装扮前后对比、月卡三条权益  
3. 短视频：「从路边摊到商场」成长切片；装扮开箱  
4. 双周小更（任务/装扮），6～8 周一中更（新业态）  
5. 未达 DAU 时优先留存与内容，**不要**加广告或加重 pay-to-win  

## 统计（正式版接入）

- 留存：D1 / D7  
- 漏斗：进入商店 → 点击商品 → 支付成功  
- 内容：各业态解锁率、任务完成率
