# 家长上架清单（必做才能真正收款）

开发者与收款账号必须由 **满 18 岁的家长** 办理。孩子可以负责玩法与内容，不能独自签约商店。

## 账号与费用

1. **Apple Developer**（上架 iOS）：约 $99/年，需信用卡与成人身份  
2. **Google Play Console**（上架 Android）：一次性约 $25  
3. **国内安卓商店**（可选：应用宝/华为等）：按各平台要求企业或个人资质  
4. 准备：身份证、银行卡、可接收验证码的手机号、公司或个人收款账户  

## 产品准备

- [ ] 应用名称、图标、截图、简介（突出「开店成长 + 装扮 + 无广告」）  
- [ ] 适龄提示 / 年龄分级填写  
- [ ] 隐私政策 URL（见 [`隐私政策草稿.md`](./隐私政策草稿.md)）  
- [ ] 用户协议与退款说明  
- [ ] 内购商品与本游戏 `GameConfig.products` 一一对应配置  

## 内购（IAP）

1. 在商店后台创建：月卡订阅、季卡、钻石包、主题、装扮  
2. 将原型 `js/iap.js` 的 `MODE` 从 `sandbox` 改为对接真实 SDK（Capacitor / 原生）  
3. 服务端校验收据（防改钻石）；Web 原型阶段仅为本地沙盒  

## 合规

- 购买流程走系统确认 / 家庭共享审批  
- 文案避免催促儿童独自付费  
- 中国区若触发防沉迷/实名政策，按当时法规接入  

## 软启指标（见 [`软启与上架冲量.md`](./软启与上架冲量.md)）

先小范围试玩，看 D1、付费率，再放量。
