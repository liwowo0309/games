# 《开口生活》

在会长大的 2D 生活里，用英语把今天的事说完。适龄小学二年级到六年级。产品说明见 [`PRD.md`](./PRD.md)。

## 怎么打开

用本地网页服务打开，语音才能用（浏览器不让 `file://` 用麦克风）。请用 Chrome 或 Edge，按住说话，并允许麦克风。听完对方的话，用自己的英语回答，意思接近就算过。

```bash
# 在仓库根目录
npx --yes serve -p 4173
```

然后访问 `http://localhost:4173/newgame/home/`。

开场在**家里**。街上地图更大，镜头跟着人走。可以进家、小店、诊所、餐厅、公园、车站和学校。点摊位上的绿色「看摊」能看见摊上卖什么。开口说话和做完一件事会赚金币。右上角「回家」会立刻回到家里。

同一人多件事时会轮换：例如妈妈会轮到买菜、早餐、家务、洗手；妹妹会轮到蹦蹦、下雨、生日、朋友来玩。

## 人与场景

| 谁 | 在哪 | 练习 |
|----|------|------|
| 妈妈 | 家里厨房 | 买菜、早餐、帮忙做家务、吃饭前洗手 |
| 爸爸 | 家里客厅 | 找书包、收书包、聊今天 |
| 奶奶 | 家里 | 说感受、Good night、浇花 |
| 妹妹 | 家里 / 院子 | 要不要出去蹦、下雨回家、生日派对、朋友来玩 |
| 店员 | 小店里面 | 买菜后半段、结账、货架问路；货架上的菜和面包用金币买 |
| 摊主 | 街上摊位 | 点摊面看 ice cream / juice / cake，也可以跟摊主说话 |
| 同学 Leo | 学校门口 / 教室 | 要不要进学校、教室里换话题、借文具 |
| 老师 | 教室 | 一进教室自动上英语课（按年级轮换题目）、课堂上说想法 |
| 同学 Mia | 教室 | 自我介绍、爱好 |
| Ken / Amy | 操场 | 一起打球、传球投篮、轮流上场、运动会加油 |
| 图书老师 | 图书室 | 借书、安静 |
| 医生 | 诊所 | How do you feel? / I have a headache |
| 服务员 | 餐厅 | What would you like? / I'd like noodles |
| Ben | 公园 | Shall we play? / 找小狗（颜色、大小） |
| 司机 | 车站 | Where are you going? / I'm going to school |

二年级可以说 `Yes, I want.`；六年级要补 because。说完进学校，不是只站在门口。

## 生活细节清单（PRD 对齐）

家里：买菜、早餐、蹦蹦、找东西、家务、晚安、洗手、收书包、浇花、生日、朋友来玩。  
学校：进校、上课、举手、认识同学、借文具、打球、加油、借书。  
外面：结账、小摊、下雨、诊所、餐厅、公园玩、找狗、车站、小店问路。
